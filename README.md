# WeatherParser 🌤️

Веб-приложение и консольная утилита (CLI) для парсинга, сохранения и отображения данных о погоде. Проект построен на базе **FastAPI** и использует **SQLite** в качестве легковесного и автономного хранилища данных.

Благодаря модульной архитектуре, проект поддерживает гибридный формат работы: сбор данных через консольный интерфейс (идеально для автоматизации по расписанию) и отображение накопленной истории через современный веб-интерфейс в тёмном неоновом стиле.

## 🚀 Основные возможности

*   **Гибридный запуск:** Работа в режиме асинхронного веб-сервера или независимой консольной утилиты.
*   **Оптимизация сетевого слоя:** Интеграция с OpenWeatherMap API с использованием единой сессии соединений (`Keep-Alive`) на базе `httpx2`.
*   **Производительность и безопасность БД:** Хранилище SQLite с поддержкой пула соединений и режима `WAL` (Write-Ahead Logging). Веб-сайт мгновенно читает историю без блокировок, даже когда консольный парсер параллельно пишет новые данные.
*   **Асинхронность (Non-blocking I/O):** Синхронные дисковые операции с SQLite вынесены в фоновый пул потоков через `run_in_threadpool`, что исключает "зависание" интерфейса FastAPI.
*   **Защита от спама и атак:** Ограничение частоты запросов с помощью `SlowAPI` (Rate Limiting) и 100% защита от XSS-инъекций на фронтенде за счёт экранирования данных.
*   **Надёжное тестирование:** Изолированная тестовая среда с автоматической очисткой таблиц и подменой пространств имён (`monkeypatch`), исключающая случайные запросы в реальный интернет во время проверок.

## 🛠️ Стек технологий

*   **Бэкенд:** Python 3.10+, FastAPI 0.141.1, Uvicorn 0.54.0
*   **Работа с сетью:** httpx2 2.13.1
*   **База данных:** SQLite (в режиме WAL)
*   **Защита API:** SlowAPI 0.1.9 (Rate Limiter)
*   **Тестирование:** Pytest 8.3.4
*   **Фронтенд:** HTML5 / CSS3 (Тёмная киберпанк-тема, адаптивная сетка CSS Grid и Flexbox)

## 📦 Установка и настройка

### 1. Клонирование репозитория
```bash
git clone https://github.com
cd WeatherParser
```

### 2. Настройка виртуального окружения и зависимостей
```bash
python -m venv venv
source venv/bin/activate  # Для Linux/macOS
# или
venv\Scripts\activate     # Для Windows

pip install -r requirements.txt
```

### 3. Настройка переменных окружения
Переименуйте шаблон конфигурационного файла `.env.example` в `.env`:
```bash
mv .env.example .env  # Или используйте 'cp' для копирования
```
Откройте созданный файл `.env` и укажите ваш API-ключ (получить бесплатно можно на [OpenWeatherMap](https://openweathermap.org)):
```env
OWM_API_KEY=твой_ключ_от_openweathermap
APP_HOST=127.0.0.1
APP_PORT=8000
```

## 💻 Использование

Приложение имеет две независимые точки входа.

### Режим 1: Веб-интерфейс (FastAPI)
Для запуска веб-сервера выполните команду:
```bash
python app.py
```
После запуска интерфейс в тёмном неоновом стиле будет доступен по адресу: `http://127.0.0.1:8000`  
Интерактивная интерактивная документация API (Swagger): `http://127.0.0`

### Режим 2: Консольная утилита (CLI Парсер)
Для ручного сбора погоды в базу данных или просмотра истории прямо через терминал используйте `main.py`:

*   **Парсинг города (по умолчанию Краснодар):**
    ```bash
    python main.py --city "Moscow"
    ```
*   **Просмотр последних N запросов из базы:**
    ```bash
    python main.py --history 5
    ```
*Совет: Консольный скрипт можно добавить в планировщик задач (например, **Cron** в Linux) для регулярного автоматического сбора статистики погоды в фоновом режиме.*

## 🧪 Тестирование

В проекте настроена автоматическая конфигурация путей импорта в файле `pyproject.toml`. Для запуска юнит-тестов и интеграционных тестов выполните в корне репозитория команду:
```bash
pytest
```
Тесты работают полностью автономно в изолированной среде, перехватывают вызовы функций «под капотом» FastAPI и автоматически очищают базу данных до и после каждого прогона.

## 📁 Структура проекта

```text
├── static/            # Стили (style.css в стиле киберпанк) и скрипты фронтенда
├── templates/         # HTML-шаблоны страниц (index.html) с XSS-защитой

├── main.py            # Точка входа для консольного CLI-парсера с обработкой флагов
├── .env.example       # Шаблон конфигурационного файла для разработчиков
├── pyproject.toml     # Конфигурацияpytest (настройка путей и фильтрация предупреждений)

```
